# Ростислав Янкун
Під час виконання лабораторної роботи я ознайомився з процесом спільної розробки програмного забезпечення за допомогою Git та GitHub. Я навчився працювати з fork, clone, branch, commit, merge та pull request.
Під час роботи я краще зрозумів принципи контролю версій та спільної роботи над проєктами. Особливо корисним було ознайомитися з механізмом Pull Request та можливістю вносити зміни через окрему feature-гілку.
